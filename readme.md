# Royma_Vison-0.02 使用说明

### 环境配置

**qt ->6.1.0**

**jsoncpp -1.9.5**

**halcon-2305**

**saige-2.6.3**

**C++17**

**cmake-3.16**

### 使用介绍

#### 项目构建

目前主要只有推理功能，一切基于项目文件夹，首次使用要先新建项目文件夹

![image-20251028112226321](C:\Users\zydon\AppData\Roaming\Typora\typora-user-images\image-20251028112226321.png)

新建后会立刻创建需要的目录结构，

```
├───non_train
│   ├───image
│   └───label
└───train
    ├───image
    └───label
```

下次打开只要选择这个根目录即可。

首次新建项目后需要添加图片，图片默认添加到非训练集在非训练集中可以单选/多选需要的图片项目右击删除或者添加到训练集。（删除会直接删除图片文件，请谨慎操作）

#### 推理

目前只支持赛视seg模型，我们需要点击

![image-20251028112807771](C:\Users\zydon\AppData\Roaming\Typora\typora-user-images\image-20251028112807771.png)

进入推理模型加载界面选择模型文件和模型类型，其他是可选参数，点击确定后进入模型加载。

##### 即时推理

在模型加载完毕后点击即时推理框，此时再点击训练集/非训练集中的项目即可进行快速推理并显示到图像上。

##### 批量推理

在模型加载页面选择批量推理，在模型加载完毕之后会进行批量推理，此时只要勾选显示推理结果，无论现在软件有没有添加模型都可以显示推理结果。
